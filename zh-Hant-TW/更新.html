更新日誌

1.12.0（2026-09-04）​

新增（PhoenixClear 同步上游 CyuClear 1.4.3）​

  • 管理員安全傳送：/phoenixclear tp <世界> <x> [y] <z>（也支援只給區塊座標），自動尋找可站立落點（避開岩漿/火/仙人掌，地獄從 120 格往下逐格找），落地預設 5 秒免傷
  • 一鍵返回：/phoenixclear back 回到上次傳送前的位置（原點記憶預設 5 分鐘過期）
  • 現場單區塊清理：/phoenixclear here [items|entities|all] 只清理腳下這一個區塊，不影響全服
  • 熱點詳情頁新增「前往該區塊」按鈕（終界珍珠圖示），點一下直接傳送到該熱點
  • 區塊過載提示帶「前往查看」按鈕（管理員可見，點擊直達出事座標）
  • 11 個新 PAPI 變數：當前區塊座標/狀態/是否熱點/是否熔斷/觸發次數/歷史清理量，以及全服熱點與熔斷總數
  • 新配置節 teleport.landing-protection.* / teleport.back.* / here-cleanup.enabled

修復​

  • PhoenixLevel：全新安裝時不再刷「舊資料遷移失敗：no such table AkariLevel_Member」——遷移前先探測舊表是否存在，沒有就靜默跳過；配置模板補上 migration 節（原 1.11.1 內容，已併入本版）
  • 上游 1.4.3 的熱點詳情選單最後一行寫成了 10 個字元（#C#T#R#B#X），第 10 個字元會算到本行之外，導致關閉按鈕既不顯示也點不到；已壓回 9 個字元 C#T#R#B#X

說明​

  • 上游把說明選單改成了點擊翻頁樣式、並恢復了啟動橫幅，這兩項未採納（此前按你的要求：說明不要點擊互動、不要啟動刷屏）
  • 上游沒有提升配置版本號，所以已有的 plugins/PhoenixClear/config.yml 不會自動補上新配置節；不改也能用（走預設值），詳見週期清理頁

1.11.0（2026-09-02）​

新增（PhoenixLevel 會員等級）​

  • PhoenixLevel 等級系統：融合 AkariLevel 並以 TabooLib + Kotlin 源碼級重寫
    • 多等級組獨立運行（每套等級組自己的等級範圍/公式/條件/動作）
    • 經驗公式白名單解析（+ - * / % ( ) 與 level 變數），壞公式拒絕載入不崩服
    • 經驗來源訂閱倍率（指令/MythicMobs/原版經驗可分別調倍）
    • 升級條件與動作走 Kether（Condition / Action），升級前事件可取消
    • MythicMobs 5.x 經驗掉落（怪物設定 Exp-Drop，區間數量+機率），掉落事件可取消
    • 30+ PlaceholderAPI 變數（進度條/跨級經驗統計等）
    • 資料按 UUID 存入 Phoenix 統一資料庫（phoenix_level_members 表），改名不丟資料
    • 舊 AkariLevel 資料自動遷移（生成 migration-report.txt 報告）
  • 獨立指令 /phoenixlevel（reload / levelgroup / member level|exp|levelup），權限 phoenixlevel.* 四節點

構建​

  • PhoenixCESkin 內核同步至 YiyunCEskin 1.3.1（隨 1.10.0 系列完成），BootProbe 補齊 PhoenixLevel 十個核心類載入驗證

1.10.0（2026-09-01）​

變更（PhoenixMessageBridge 重構）​

  • 回歸原版 MessageBridge 的全攔截處理流程：攔截 → 標籤分流 → 轉發/取消
  • 新增取消轉發開關：攔截後的訊息可設定是否繼續原樣發送（預設取消）
  • 新增 BetterHud popup 的 Kether 動作：
    • show popup "名" —— 顯示 popup
    • hide popup "名" —— 隱藏 popup
  • 標籤分流支援 scripts.<標籤> Kether 腳本（每次分流時執行），規則匹配命中執行 commands Kether
  • 模組檔名 MsgForward → MessageBridge（目錄 plugins/PhoenixMessageBridge/）

同步（PhoenixCESkin 1.3.1）​

  • 內核同步 YiyunCEskin 1.3.1：皮膚預覽權限分層（查看/預覽/套用）、preview.allow-without-access 設定、預覽事件 SkinPreviewEvent、預覽存取校驗 GUARD 階段優先

修復（1.9.x 系列）​

  • 交易提示顯示為節點名（語言鍵扁平化修復）、自交易攔截、邀請選單內建變數不顯示
  • 交易會話原子化、Vault 交易結果判定、邀請返點負數等（詳見 1.9.0）

1.9.0（2026-09-01）​

修復（交易 PhoenixTrade）​

  • 會話管理全面原子化：同一玩家無法被兩筆併發交易覆蓋；舊會話結束時不再誤刪新會話
  • /phoenixtrade accept <玩家> 只接受真實收到且未過期的請求，並消費該請求；無法再憑命令與任意線上玩家直接開局
  • 交易進入明確生命週期（開啟 → 倒計時 → 結算 → 完成/取消），成交只可能發生一次；結算拋異常也會走返還路徑，不再可能重複扣款
  • 玩家退出/被踢時自動取消並返還交易、清理請求與快取
  • 外掛主動關閉只在當前視窗仍是交易介面時執行，杜絕關閉玩家新開介面
  • Vault 存取改為讀取 EconomyResponse.transactionSuccess()，經濟外掛拒絕操作不再被誤判為成功；扣款/入賬/回滾失敗均記錄原因
  • 金幣按鈕檔位改回每次過載重算，修改 Amounts 後 /phoenixtrade reload 立即生效
  • data.yml 過載先清快取再讀入，外部修改能正確反映
  • 過載流程改為主執行緒固定順序執行，成功/失敗提示與實際狀態一致；新增失敗提示詞條
  • 測試交易關閉不再傳送兩條重複提示；移除重複的金額校驗與死程式碼

修復（邀請 PhoenixInvite）​

  • 選單按鈕配置改為嚴格按當前選單讀取（舊版按按鈕字元全域性查詢，G/A/P/N 會串到其他選單的配置導致變數顯示錯誤）
  • 貢獻返點扣除改為資料庫條件更新（餘額足夠才扣），管理員扣除/兌換不再可能把餘額扣成負數

1.8.0（2026-08-31）​

新增​

  • PhoenixInvite 邀請激勵系統：融合 ALInvite 並以 TabooLib + Kotlin 原始碼級重寫
    • 專屬邀請碼（成書輸入 / 命令 / 選單三種繫結方式）
    • 老玩家累計邀請里程碑（三態選單 + 手動/自動領取 + 全服公告）
    • 禮包商店（老玩家購禮包提升新玩家獎勵，限時禮包過期自動回退）
    • 許可權組獎勵（新玩家升級獎勵邀請人，支援離線補發）
    • 點券充值返點（givedj，許可權組比例 + 貢獻模式 + 防重複）
    • 自動老玩家（PAPI 線上時長判定）
    • 排行榜三榜 + 30+ PAPI 變數
  • PhoenixTrade 玩家對玩家交易：融合 GoodsTrade 並重寫
    • 雙欄交易介面、雙重確認 + 可撤回倒計時
    • Vault 金幣交易（負數報價 / 淨額單筆轉賬 / 失敗回滾）
    • 潛行右鍵發起、可點選聊天訊息接受、toggle 拒絕
    • 物品黑名單、交易免傷/禁足、沙盒測試交易
  • /phoenix lang 線上切換語言

修復​

  • Kether 以控制檯身份執行時的相容問題（adaptCommandSender）
  • 交易請求不能對自己發起（自交易攔截）
  • 邀請選單獎勵描述 {reward_lore_N} 佔位符逐行展開
  • 語言詞條全面改為扁平鍵，修復模組訊息顯示為詞條名的問題

移除（相對原外掛）​

  • ALInvite：跨服公告同步（空轉功能）、每日返點上限（原版即未生效）
  • GoodsTrade：NBT 黑名單（1.21 無裸 NBT）、bStats、XSeries、1.12 相容層

歷史​

更早版本（1.1.0 ~ 1.7.6）的融合歷程：PhoenixBan、PhoenixCDK、PhoenixSell、PhoenixCESkin、PhoenixClear、PhoenixBorder、PhoenixTintHealth、PhoenixSeamless、PhoenixMessageBridge 依次整合為一個外掛，詳見倉庫 Releases。
