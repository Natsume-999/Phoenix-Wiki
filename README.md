# Phoenix-Wiki

**Phoenix 整合插件** 的官方使用文档（Docusaurus 站点）。

Phoenix 是一款为 Paper / Leaf 1.21.11 打造的一体化整合插件：封禁管理、兑换码、出售系统、物品皮肤、周期清理、世界边界、邀请激励、玩家交易等十余个模块融合在一个 jar 里，每个模块拥有独立的配置目录与命令。

## 在线阅读

文档站部署于 GitHub Pages：`https://natsume-999.github.io/Phoenix-Wiki/`

## 本地开发

```bash
npm install
npm start        # 本地预览
npm run build    # 构建生产版本
```

## 目录

- `docs/` — 文档正文（中文）
- `.github/workflows/build.yml` — GitHub Actions 自动构建并部署 Pages
