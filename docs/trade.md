# PhoenixTrade 玩家对玩家交易

双方面对面的**安全交易**：把物品放进交易界面自己一侧，双方确认 → 5 秒倒计时 → 成交交换。任一方提前关闭界面即取消并**全额返还**。可选支持 Vault 金币交易。

## 玩家玩法全流程

### 1️⃣ 发起交易（三种方式）

| 方式 | 操作 |
|---|---|
| 潜行右键 | **蹲下 + 右键点击**目标玩家（默认开启） |
| 命令 | `/phoenixtrade sendtrade <玩家名>` |
| 强制（管理员） | `/phoenixtrade trade <玩家1> <玩家2>` |

发起后对方会收到一条**可点击的聊天消息**「[点击接受]」，点击即进入交易（30 秒内有效，重复发起有冷却）。

:::tip 拒绝打扰
不想被交易？`/phoenixtrade toggle` 一键关闭交易请求（状态会保存，重进服务器依然生效），或用 `/phoenixtrade toggle false` 明确关闭、`true` 打开。
:::

### 2️⃣ 交易界面操作

界面为 54 格双栏：

```
# # # # @ # # # #
# S S S @ T T T #     S = 发起者格子（左 4 列）
# S S S @ T T T #     T = 接收者格子（右 4 列）
# S S S @ T T T #     @ = 分隔板（显示双方需支付金额）
# M M M M @ M M M #   M = 金币按钮（装了 Vault 才显示）
# _ R R R _ R R R #   R = 确认按钮（左右各 3 格等价）
```

操作规则：

1. 把想交易的物品放进**自己一侧**（只能操作自己的格子；shift 放置与双击吸收被禁止，物品需逐个放取）；
2. 点底部自己的**确认按钮**：确认后自己的物品锁定（再点一次可撤回）；
3. **对方任何改动（物品/金币报价）都会重置你的确认状态**，界面会提示，请重新检查后再确认；
4. 双方都确认后进入 **5 秒倒计时**：确认按钮变成蓝色并显示倒数数字（5→1），期间**再点一次确认按钮 = 撤回**；
5. 倒计时结束自动成交：物品互换 + 金币净额结算，双方收到成功提示与音效；
6. **倒计时中直接关闭界面 = 取消交易**（双方物品全额返还）。

### 3️⃣ 金币交易

- 金币按钮**左键加、右键减**，每按一次增减对应档位金额（默认 1000 / 10000 两档，最多 4 档）；
- 报价显示在中间分隔板上（`XX 需支付: xxx`）；
- 支持**负数报价**（需开启 `Allow-Negative`）：负数等价于要求对方付钱；
- 成交时按**净额单笔转账**：例如你出 5000、对方出 3000，实际只发生一笔「你→对方 2000」的转账；
- 结算前会再次校验双方余额，**余额不足或经济插件拒绝 → 交易取消、物品全额返还**（物品绝不动）。

### 4️⃣ 沙盒测试（管理员）

`/phoenixtrade test [虚拟玩家名]`：管理员单人操作双方区域的完整流程演练——**不转移物品、不扣款**，用于上线前检查界面与配置。

## 命令一览

| 命令 | 权限 | 说明 |
|---|---|---|
| `/phoenixtrade` | - | 帮助 |
| `/phoenixtrade sendtrade <玩家>` | `phoenixtrade.sendtrade` | 发起交易请求 |
| `/phoenixtrade accept [玩家名]` | `phoenixtrade.accept` | 接受请求（只有一条时可省略名字） |
| `/phoenixtrade toggle [true\|false]` | `phoenixtrade.toggle` | 开关接收交易 |
| `/phoenixtrade trade <玩家1> <玩家2>` | `phoenixtrade.trade`（OP） | 强制开启两人交易 |
| `/phoenixtrade test [虚拟名]` | `phoenixtrade.test`（OP） | 沙盒交易 |
| `/phoenixtrade reload` | `phoenixtrade.reload`（OP） | 重载配置（会中断所有进行中交易） |

## 配置详解（config.yml）

```yaml
Trade:
  # 成交前的倒计时秒数（界面按钮会显示倒数数字；上限 64）
  Wait-Time: 5

  Economy:
    Enable: true            # Vault 金币交易总开关（false 则金币按钮不显示）
    Allow-Negative: false   # 允许负数报价（负数 = 要求对方支付）
    Amounts:                # 金币按钮档位，从小到大，最多 4 个
      - 1000
      - 10000

  Triggers:
    Shift-Right-Click: true # 蹲下右键发起交易

  Safe:
    Damage: false           # 交易期间玩家免伤
    Move: false             # 交易期间禁止移动/被推动

  Item-BlackList:           # 物品黑名单（确认时校验，命中则无法确认）
    Enable: false
    Lore:                   # 描述包含匹配（任意一行命中即拦截）
      - "禁止交易"
    Name:                   # 名字包含匹配
      - "XXX"
```

:::note 关于 NBT 黑名单
原版 GoodsTrade 支持 NBT 黑名单；Minecraft 1.21 起物品使用 Data Components 存储，已没有可按路径匹配的裸 NBT，因此 PhoenixTrade 移除了该功能。名字/描述黑名单保留，配合 NeigeItems 等插件的「绑定」类描述即可实现同类效果。
:::

## 界面自定义（view.yml）

`plugins/PhoenixTrade/view.yml` 可改每个按钮的材质 / 名字 / 描述 / 自定义模型数据，不配置的键用内置默认：

```yaml
button:
  "#":                      # 背景填充
    material: black_stained_glass_pane
    name: " "
    lore: ["&7"]
  "@":                      # 中间分隔板（金币信息由插件追加）
  "F":                      # 发起者确认按钮
  "F:Yes":                  # 发起者确认后
  "T":                      # 接收者确认按钮
  "T:Yes":                  # 接收者确认后
  "Wait":                   # 双方确认后的倒计时按钮（数量=剩余秒数）
  "CancelReady":            # 倒计时中对方撤回后显示的按钮
  "Money":                  # 金币按钮通用样式（%amount% 替换档位金额）
    name: "&6调整金币: &e%amount%"
    lore:
      - "&a左键: 增加 %amount%"
      - "&c右键: 减少 %amount%"
  "Money-1":                # 单独覆盖第 1 档
  "Money-2":
  "Money-3":
  "Money-4":
```

## 安全机制清单

| 机制 | 说明 |
|---|---|
| 一侧隔离 | 只能操作自己一侧的格子，对方格子点击直接拦截 |
| 锁定 | 自己确认后物品与金币报价锁定，需撤回才能改 |
| 确认重置 | 对方改动任何内容 → 双方确认状态清零，强制重新检查 |
| 倒计时撤回 | 倒计时中再点确认 = 撤回；对方会看到「对方取消」按钮 |
| 黑名单 | 确认时校验物品黑名单，命中禁止确认 |
| 余额终审 | 倒计时结束成交时再次校验双方余额，失败则整笔取消返还 |
| 回滚 | 金币先扣后转，入账失败自动回滚扣款（物品尚未移动） |
| 关闭即取消 | 倒计时中关界面 = 取消；光标上的物品也会被收回背包 |
| 自交易拦截 | 不能对自己发起交易或强制开启自我交易 |

## 数据与占位符

- 玩家的 toggle 状态保存在 `plugins/PhoenixTrade/data.yml`；
- `%phoenixtrade_stats%` → 该玩家是否接受交易（true / false），可配合菜单/计分板提示。
