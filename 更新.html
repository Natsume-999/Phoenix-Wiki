更新日志

1.8.0（2026-08-31）​

新增​

  • PhoenixInvite 邀请激励系统：融合 ALInvite 并以 TabooLib + Kotlin 源码级重写
    • 专属邀请码（成书输入 / 命令 / 菜单三种绑定方式）
    • 老玩家累计邀请里程碑（三态菜单 + 手动/自动领取 + 全服公告）
    • 礼包商店（老玩家购礼包提升新玩家奖励，限时礼包过期自动回退）
    • 权限组奖励（新玩家升级奖励邀请人，支持离线补发）
    • 点券充值返点（givedj，权限组比例 + 贡献模式 + 防重复）
    • 自动老玩家（PAPI 在线时长判定）
    • 排行榜三榜 + 30+ PAPI 变量
  • PhoenixTrade 玩家对玩家交易：融合 GoodsTrade 并重写
    • 双栏交易界面、双重确认 + 可撤回倒计时
    • Vault 金币交易（负数报价 / 净额单笔转账 / 失败回滚）
    • 潜行右键发起、可点击聊天消息接受、toggle 拒绝
    • 物品黑名单、交易免伤/禁足、沙盒测试交易
  • /phoenix lang 在线切换语言

修复​

  • Kether 以控制台身份执行时的兼容问题（adaptCommandSender）
  • 交易请求不能对自己发起（自交易拦截）
  • 邀请菜单奖励描述 {reward_lore_N} 占位符逐行展开
  • 语言词条全面改为扁平键，修复模块消息显示为词条名的问题

移除（相对原插件）​

  • ALInvite：跨服公告同步（空转功能）、每日返点上限（原版即未生效）
  • GoodsTrade：NBT 黑名单（1.21 无裸 NBT）、bStats、XSeries、1.12 兼容层

历史​

更早版本（1.1.0 ~ 1.7.6）的融合历程：PhoenixBan、PhoenixCDK、PhoenixSell、PhoenixCESkin、PhoenixClear、PhoenixBorder、PhoenixTintHealth、PhoenixSeamless、PhoenixMessageBridge 依次整合为一个插件，详见仓库 Releases。
