更新日志

1.12.0（2026-09-04）​

新增（PhoenixClear 同步上游 CyuClear 1.4.3）​

  • 管理员安全传送：/phoenixclear tp <世界> <x> [y] <z>（也支持只给区块坐标），自动寻找可站立落点（避开岩浆/火/仙人掌，下界从 120 格往下逐格找），落地默认 5 秒免伤
  • 一键返回：/phoenixclear back 回到上次传送前的位置（原点记忆默认 5 分钟过期）
  • 现场单区块清理：/phoenixclear here [items|entities|all] 只清理脚下这一个区块，不影响全服
  • 热点详情页新增「前往该区块」按钮（末影珍珠图标），点一下直接传送到该热点
  • 区块过载提示带「前往查看」按钮（管理员可见，点击直达出事坐标）
  • 11 个新 PAPI 变量：当前区块坐标/状态/是否热点/是否熔断/触发次数/历史清理量，以及全服热点与熔断总数
  • 新配置节 teleport.landing-protection.* / teleport.back.* / here-cleanup.enabled

修复​

  • PhoenixLevel：全新安装时不再刷「旧数据迁移失败：no such table AkariLevel_Member」——迁移前先探测旧表是否存在，没有就静默跳过；配置模板补上 migration 节（原 1.11.1 内容，已并入本版）
  • 上游 1.4.3 的热点详情菜单最后一行写成了 10 个字符（#C#T#R#B#X），第 10 个字符会算到本行之外，导致关闭按钮既不显示也点不到；已压回 9 个字符 C#T#R#B#X

说明​

  • 上游把帮助菜单改成了点击翻页样式、并恢复了启动横幅，这两项未采纳（此前按你的要求：帮助不要点击交互、不要启动刷屏）
  • 上游没有提升配置版本号，所以已有的 plugins/PhoenixClear/config.yml 不会自动补上新配置节；不改也能用（走默认值），详见周期清理页

1.11.0（2026-09-02）​

新增（PhoenixLevel 会员等级）​

  • PhoenixLevel 等级系统：融合 AkariLevel 并以 TabooLib + Kotlin 源码级重写
    • 多等级组独立运行（每套等级组自己的等级范围/公式/条件/动作）
    • 经验公式白名单解析（+ - * / % ( ) 与 level 变量），坏公式拒绝加载不崩服
    • 经验来源订阅倍率（命令/MythicMobs/原版经验可分别调倍）
    • 升级条件与动作走 Kether（Condition / Action），升级前事件可取消
    • MythicMobs 5.x 经验掉落（怪物配置 Exp-Drop，区间数量+概率），掉落事件可取消
    • 30+ PlaceholderAPI 变量（进度条/跨级经验统计等）
    • 数据按 UUID 存入 Phoenix 统一数据库（phoenix_level_members 表），改名不丢数据
    • 旧 AkariLevel 数据自动迁移（生成 migration-report.txt 报告）
  • 独立命令 /phoenixlevel（reload / levelgroup / member level|exp|levelup），权限 phoenixlevel.* 四节点

构建​

  • PhoenixCESkin 内核同步至 YiyunCEskin 1.3.1（随 1.10.0 系列完成），BootProbe 补齐 PhoenixLevel 十个核心类加载验证

1.10.0（2026-09-01）​

变更（PhoenixMessageBridge 重构）​

  • 回归原版 MessageBridge 的全拦截处理流程：拦截 → 标签分流 → 转发/取消
  • 新增取消转发开关：拦截后的消息可配置是否继续原样发送（默认取消）
  • 新增 BetterHud popup 的 Kether 动作：
    • show popup "名" —— 显示 popup
    • hide popup "名" —— 隐藏 popup
  • 标签分流支持 scripts.<标签> Kether 脚本（每次分流时执行），规则匹配命中执行 commands Kether
  • 模块文件名 MsgForward → MessageBridge（目录 plugins/PhoenixMessageBridge/）

同步（PhoenixCESkin 1.3.1）​

  • 内核同步 YiyunCEskin 1.3.1：皮肤预览权限分层（查看/预览/应用）、preview.allow-without-access 配置、预览事件 SkinPreviewEvent、预览访问校验 GUARD 阶段优先

修复（1.9.x 系列）​

  • 交易提示显示为节点名（语言键扁平化修复）、自交易拦截、邀请菜单内置变量不显示
  • 交易会话原子化、Vault 事务结果判定、邀请返点负数等（详见 1.9.0）

1.9.0（2026-09-01）​

修复（交易 PhoenixTrade）​

  • 会话管理全面原子化：同一玩家无法被两笔并发交易覆盖；旧会话结束时不再误删新会话
  • /phoenixtrade accept <玩家> 只接受真实收到且未过期的请求，并消费该请求；无法再凭命令与任意在线玩家直接开局
  • 交易进入明确生命周期（打开 → 倒计时 → 结算 → 完成/取消），成交只可能发生一次；结算抛异常也会走返还路径，不再可能重复扣款
  • 玩家退出/被踢时自动取消并返还交易、清理请求与缓存
  • 插件主动关闭只在当前窗口仍是交易界面时执行，杜绝关闭玩家新开界面
  • Vault 存取改为读取 EconomyResponse.transactionSuccess()，经济插件拒绝操作不再被误判为成功；扣款/入账/回滚失败均记录原因
  • 金币按钮档位改回每次重载重算，修改 Amounts 后 /phoenixtrade reload 立即生效
  • data.yml 重载先清缓存再读入，外部修改能正确反映
  • 重载流程改为主线程固定顺序执行，成功/失败提示与实际状态一致；新增失败提示词条
  • 测试交易关闭不再发送两条重复提示；移除重复的金额校验与死代码

修复（邀请 PhoenixInvite）​

  • 菜单按钮配置改为严格按当前菜单读取（旧版按按钮字符全局查找，G/A/P/N 会串到其他菜单的配置导致变量显示错误）
  • 贡献返点扣除改为数据库条件更新（余额足够才扣），管理员扣除/兑换不再可能把余额扣成负数

1.8.0（2026-08-31）​

新增​

  • PhoenixInvite 邀请激励系统：融合 ALInvite 并以 TabooLib + Kotlin 源码级重写
    • 专属邀请码（成书输入 / 命令 / 菜单三种绑定方式）
    • 老玩家累计邀请里程碑（三态菜单 + 手动/自动领取 + 全服公告）
    • 礼包商店（老玩家购礼包提升新玩家奖励，限时礼包过期自动回退）
    • 权限组奖励（新玩家升级奖励邀请人，支持离线补发）
    • 点券充值返点（givedj，权限组比例 + 贡献模式 + 防重复）
    • 自动老玩家（PAPI 在线时长判定）
    • 排行榜三榜 + 30+ PAPI 变量
  • PhoenixTrade 玩家对玩家交易：融合 GoodsTrade 并重写
    • 双栏交易界面、双重确认 + 可撤回倒计时
    • Vault 金币交易（负数报价 / 净额单笔转账 / 失败回滚）
    • 潜行右键发起、可点击聊天消息接受、toggle 拒绝
    • 物品黑名单、交易免伤/禁足、沙盒测试交易
  • /phoenix lang 在线切换语言

修复​

  • Kether 以控制台身份执行时的兼容问题（adaptCommandSender）
  • 交易请求不能对自己发起（自交易拦截）
  • 邀请菜单奖励描述 {reward_lore_N} 占位符逐行展开
  • 语言词条全面改为扁平键，修复模块消息显示为词条名的问题

移除（相对原插件）​

  • ALInvite：跨服公告同步（空转功能）、每日返点上限（原版即未生效）
  • GoodsTrade：NBT 黑名单（1.21 无裸 NBT）、bStats、XSeries、1.12 兼容层

历史​

更早版本（1.1.0 ~ 1.7.6）的融合历程：PhoenixBan、PhoenixCDK、PhoenixSell、PhoenixCESkin、PhoenixClear、PhoenixBorder、PhoenixTintHealth、PhoenixSeamless、PhoenixMessageBridge 依次整合为一个插件，详见仓库 Releases。
