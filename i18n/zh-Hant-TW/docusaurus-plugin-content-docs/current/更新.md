# 更新日誌

## 1.9.0（2026-09-01）

### 修復（交易 PhoenixTrade）

- 會話管理全面原子化：同一玩家無法被兩筆併發交易覆蓋；舊會話結束時不再誤刪新會話
- `/phoenixtrade accept <玩家>` 只接受**真實收到且未過期**的請求，並消費該請求；無法再憑命令與任意線上玩家直接開局
- 交易進入明確生命週期（開啟 → 倒計時 → 結算 → 完成/取消），成交只可能發生一次；結算拋異常也會走返還路徑，不再可能重複扣款
- 玩家退出/被踢時自動取消並返還交易、清理請求與快取
- 外掛主動關閉只在當前視窗仍是交易介面時執行，杜絕關閉玩家新開介面
- Vault 存取改為讀取 `EconomyResponse.transactionSuccess()`，經濟外掛拒絕操作不再被誤判為成功；扣款/入賬/回滾失敗均記錄原因
- 金幣按鈕檔位改回每次過載重算，修改 `Amounts` 後 `/phoenixtrade reload` 立即生效
- `data.yml` 過載先清快取再讀入，外部修改能正確反映
- 過載流程改為主執行緒固定順序執行，成功/失敗提示與實際狀態一致；新增失敗提示詞條
- 測試交易關閉不再傳送兩條重複提示；移除重複的金額校驗與死程式碼

### 修復（邀請 PhoenixInvite）

- 選單按鈕配置改為**嚴格按當前選單**讀取（舊版按按鈕字元全域性查詢，`G/A/P/N` 會串到其他選單的配置導致變數顯示錯誤）
- 貢獻返點扣除改為資料庫條件更新（餘額足夠才扣），管理員扣除/兌換不再可能把餘額扣成負數

## 1.8.0（2026-08-31）

### 新增

- **PhoenixInvite 邀請激勵系統**：融合 ALInvite 並以 TabooLib + Kotlin 原始碼級重寫
  - 專屬邀請碼（成書輸入 / 命令 / 選單三種繫結方式）
  - 老玩家累計邀請里程碑（三態選單 + 手動/自動領取 + 全服公告）
  - 禮包商店（老玩家購禮包提升新玩家獎勵，限時禮包過期自動回退）
  - 許可權組獎勵（新玩家升級獎勵邀請人，支援離線補發）
  - 點券充值返點（givedj，許可權組比例 + 貢獻模式 + 防重複）
  - 自動老玩家（PAPI 線上時長判定）
  - 排行榜三榜 + 30+ PAPI 變數
- **PhoenixTrade 玩家對玩家交易**：融合 GoodsTrade 並重寫
  - 雙欄交易介面、雙重確認 + 可撤回倒計時
  - Vault 金幣交易（負數報價 / 淨額單筆轉賬 / 失敗回滾）
  - 潛行右鍵發起、可點選聊天訊息接受、toggle 拒絕
  - 物品黑名單、交易免傷/禁足、沙盒測試交易
- `/phoenix lang` 線上切換語言

### 修復

- Kether 以控制檯身份執行時的相容問題（adaptCommandSender）
- 交易請求不能對自己發起（自交易攔截）
- 邀請選單獎勵描述 `{reward_lore_N}` 佔位符逐行展開
- 語言詞條全面改為扁平鍵，修復模組訊息顯示為詞條名的問題

### 移除（相對原外掛）

- ALInvite：跨服公告同步（空轉功能）、每日返點上限（原版即未生效）
- GoodsTrade：NBT 黑名單（1.21 無裸 NBT）、bStats、XSeries、1.12 相容層
